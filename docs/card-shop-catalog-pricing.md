# 卡密商城 · 商品目录与定价方案

> 前提：商品为**外部卡密**，凭证有效性由上游保证，本系统只负责交易与交付。
> 本文回答四个问题：**卖什么（目录）、怎么分（维度）、怎么定（价格）、怎么摆（页面）**。

---

## 一、目录的第一性原理：两套分类，绝不能混

看淘宝和闲鱼，用户看到的是「话费充值 / 游戏点卡 / 会员」——那是**用户心智分类**。
但它们的后台还有另一套：发货方式、风控等级、保证金、类目资质。那是**运营分类**。

独角数卡的问题就在这里：一张 `goods` 表塞下所有字段，分类只有一个 `category`，
结果既不能按发货方式分流，也不能按风险限流。

所以本方案明确拆成两套：

| 维度 | 给谁看 | 作用 | 字段 |
|---|---|---|---|
| **品类 category** | 用户 | 导航、筛选、SEO | 树形 `parent_id` |
| **交付方式 delivery_type** | 系统 | 决定履约流程 | 1自动 2人工 3固定内容 |
| **风险等级 risk_level** | 运营 | 决定审核与限购 | 1低 2中 3高 |
| **供应商 supplier** | 采购 | 决定成本与废卡率 | 字符串 + 统计 |

一条商品 = 一个品类节点 + 一组标签。**标签不进目录树，目录树不承载风控。**

## 二、卖什么：三套目录，选一套

### 方案 A：AI 垂直（推荐）

只卖与 AI 相关的商品。理由：**你的流量已经在站内，只有 AI 相关的东西他们才会顺手买。**

```

├── ChatGPT Plus          月卡 / 季卡 / 年卡
├── Claude Pro            月卡 / 年卡
├── Gemini Advanced       月卡
└── Perplexity Pro        月卡
AI 工具订阅
├── Midjourney            基础 / 标准 / 专业
├── Cursor Pro            月卡 / 年卡
├── GitHub Copilot        月卡 / 年卡
└── Suno / Runway         月卡
AI 成品号
├── ChatGPT 账号          独享 / 共享
├── Claude 账号           独享
└── 邮箱号                谷歌 / 微软
算力与额度
├── API 额度卡            自营（走 redemption）
└── 第三方算力卡          Replicate / RunPod
教程与资料
└── 提示词包 / 部署教程   固定内容交付
```

### 方案 B：泛品类（淘宝式）

```
话费充值 / 流量包 / 视频会员 / 音乐会员 / 游戏点卡 / 游戏账号 / 软件授权 / 教育课程
```

问题很直接：**这批用户你从哪来？** apiduo 现有用户是来买 API 的，看到游戏点卡不会下单。
泛品类需要一个完全独立的流量池——那是另一个生意，不是这个站的功能。

### 方案 C：混合（A 为主 + 少量通用）

以 AI 为主，加「话费/流量」这类**低决策成本、高频**的商品做引流品。
逻辑：用户来充话费顺手看到 AI 会员，转化路径比反过来短。

**建议：先 A，跑通后再加 C 的引流品。B 直接放弃。**

## 三、定价：先算这道生死题

### 3.1 生死线公式

外部卡密生意的全部风险，可以用一个不等式概括：

```
可承受废卡率  =  毛利率  −  支付通道费率
```

超过这条线，每多卖一单都在亏钱。代入实际数据：

| 品类 | 典型毛利率 | 通道费率(易支付1%) | **可承受废卡率** | 上游实际废卡率 | 结论 |
|---|---|---|---|---|---|
| 话费/流量 | 1–3% | 1% | **0–2%** | 0.5–2% | **临界，几乎必亏** |
| 视频/音乐会员 | 5–12% | 1% | **4–11%** | 1–3% | 勉强，靠量 |
| 游戏点卡/密钥 | 3–8% | 1% | **2–7%** | 1–5% | 高风险，需验卡 |
| 软件订阅 | 15–35% | 1% | **14–34%** | 3–8% | 可行 |
| AI 成品号 | 40–120% | 1% | **39–119%** | 10–30% | 唯一宽裕 |

**这张表就是选品的答案。** 话费卡在数学上不成立：卖 100 单赚 100 块，1 张废卡赔 100 块，正好归零。

### 3.2 Stripe 会让情况更糟

Stripe 费率 `2.9% + $0.30`。卖一张 $10 的卡，实际费率是 `(0.29+0.30)/10 = 5.9%`。

代入公式：`可承受废卡率 = 毛利率 − 5.9%`——**游戏点卡直接变负数。**

结论：**小额卡密在美国通道上数学不成立。** 只有易支付（1% 左右）能撑住薄毛利品类，而它恰好是风险最高的通道。这是这个生意最根本的矛盾。

### 3.3 定价模型

四层价格，各有各的用途：

```go
CostCents      int64 // 成本价：供应商报价，绝不外露
ListPriceCents int64 // 标价：成本 / (1 - 目标毛利率)，系统算
PriceCents     int64 // 实售价：运营可覆盖，通常 = 标价
ChannelCents   int64 // 分销价：预留，P4 才用
```

自动定价公式：

```
ListPrice = ceil( CostCents / (1 - target_margin) / 100 ) * 100
```

向上取整到「元」，避免出现 `¥19.97` 这种价签。

### 3.4 三条定价纪律

1. **对标市场价，不对标成本。** 用户不关心你进货多少钱，只关心比别处贵不贵。成本只用来算**这单该不该接**。
2. **设最低价保护。** 分销价不得低于 `CostCents × 1.05`，否则代理砸盘，你连通道费都收不回。
3. **不做动态提价。** 库存紧张时提价，毛利增加但口碑崩。稀缺就限购，别涨价。

### 3.5 一个真实算例

卖 ChatGPT Plus 月卡，官方 $20：

```
采购成本      ¥120（上游代充渠道）
目标毛利率    30%
标价          120 / 0.7 = ¥171.4  →  ¥172
通道费(1%)    ¥1.72
单笔净利      ¥50.28
上游废卡率    10%  →  每 10 单赔 1 单 120 元
10 单净利     502.8 − 120 = ¥382.8
```

能活。换成话费卡：10 单净利 10 元，1 张废卡赔 100 元——**亏 90 元**。

## 五、页面信息架构

### 5.1 商城列表 `/cards`

```
[分类侧栏]          [筛选条：价格 | 销量 | 有货]
  AI 会员            ┌────────┬────────┬────────┐
  AI 工具            │ 封面    │ 封面    │ 封面    │
  AI 成品号          │ 名称    │ 名称    │ 名称    │
  算力额度           │ ¥172   │ ¥208   │ ¥118   │
  资料               │ 库存充足│ 仅剩3张 │ 售罄    │
                     └────────┴────────┴────────┘
```

要点：
- **不显示精确库存**，只显示 `充足 / 仅剩 N 张 / 售罄`。精确数字会暴露进货量。
- 「仅剩 N 张」只在 N ≤ 5 时出现，制造稀缺感但不泄露规模。

### 5.2 商品详情 `/cards/$goodsId`

固定顺序（顺序即转化率）：

1. 主图 + 名称 + 价格
2. **质保说明**（「官方封号包换，7 天内」，必须在购买按钮之上）
3. 库存状态 + 限购提示（每人限 N 件）
4. 数量选择 + 立即购买
5. 购买须知（**虚拟商品不支持 7 天无理由退货**，法律要求前置告知）
6. 商品详情（长文描述，含使用说明、失效条件、不保范围）

## 六、上架流程与风控分级

| 风险等级 | 适用品类 | 上架要求 | 履约 |
|---|---|---|---|
| 1 低 | 自营额度、资料包 | 直接上架 | 自动 |
| 2 中 | 会员代充、游戏点卡 | 需首批小样验证 | 自动 + 抽检 |
| 3 高 | 成品账号、共享号 | **人工审核 + 限购 1 + 单独收款通道** | 人工发货 |

风险等级 3 的商品建议：
- 不放首页推荐
- 单用户每日限 1 单
- 订单先进「待审核」，人工确认后发货
- 详情页不做 SEO（避免搜索引擎收录）

## 七、定价禁忌（踩了就是事故）

1. **别用浮点存金额。** `19.99 × 3` 在某些语言里不等于 `59.97`，而对账时你必须精确相等。
2. **别把成本价带到前端。** `cost_cents` 必须 `json:"-"`，任何列表接口都不能返回。
3. **别做「限时折扣」倒计时造假。** 卡密买家高度敏感，被识破一次就流失。
4. **别让分销价低于成本 × 1.05。** 代理为了冲量会砸到成本线以下，最后烂的是你的价格体系。
5. **别承诺「永久有效」。** 外部卡密的有效期由上游决定，你只能承诺质保期。承诺永久 = 无限责任。
