为什么不是一个表：任务要能被轮询、能被重试，生命周期比账单长；账单要能被聚合、能按 token / 渠道 / 用户筛选，写放大也更大。
        所以任务写 tasks，每次计费动作写 logs —— 预扣一行、结算或退款再一行，金额永远可追溯。
