## 已设计、不必再讨论的部分

原型里已经画完、开发可直接照抄的：四态（加载 / 取数失败 / 区间无数据 / 筛选无结果）、搜索与三档筛选、URL 即状态、分享链接、CSV 导出、暗色、基线带与 P50 参考线、错误聚类（首现 / 影响用户 / 状态）、重试阶梯守恒、动作队列与四种客户告警（事故 / 额度墙 / 下滑 / 沉默）。

对应文件：`design/error-dashboard-v2.html`、`design/ops-console.html`、`design/design-system.html`、`design/design-contract.md`、`design/tokens.json`。

## 明确不做

- **更多图表类型**（饼图、环形图、仪表盘）。维度已经够，换形状不加信息。
- **把错误分析做成 `/growth` 的一个 tab**。两者服务同一个决策但时间尺度不同：错误看分钟级，运营看天级。合并发生在「动作队列」这一层，不发生在图表层。

## 建议的开工顺序

`3 → 1 → 2 → 5 → 13`

3 是现成的 bug，一天能修，修完现有 incident 告警立刻变准。1+2 是所有分析页面的前提。5 成本最小、价值最直接（一根竖线）。13 决定这个看板是「看一眼就走」还是「每天真的在这里干活」。
