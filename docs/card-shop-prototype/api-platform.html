这是 apiduo 现有的控制台

两条产品线在此并列

切换器在最外层，两条线各自拥有独立的侧边栏与计费口径。买卡密的人不会撞见「系统设置」，调接口的人也不会看到「我的卡密」。

注意右上角的余额显示不同：这里显示 $18.42（API 额度），商城显示 ¥128.40（商城钱包）。两个钱包不互通——这是刻意的。

本原型只呈现结构关系，控制台页面沿用现有实现。

为什么两个钱包必须分开

  • API 额度按 token 扣费，有汇率换算、分组倍率、缓存命中折扣，账务逻辑复杂且必须精确。
  • 卡密是买断制，一次性交付，交付完成即结束，没有后续计量。
  • 混在一个钱包里，退款、对账、发票口径全部纠不清——退一张卡密要不要扣回已消耗的 token？
  • 所以：商城只卖外部卡密，自营额度充值留在钱包页。商城不出售额度卡。
